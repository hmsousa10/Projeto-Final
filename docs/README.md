Os resultados históricos descritos nos guias dizem respeito à execução e versão
indicadas; não equivalem a uma validação automática da versão atual. Os scripts
podem gerar relatórios em `docs/` ou `data/`, mas esses ficheiros locais não são
versionados. Código de avaliação, testes e procedimentos são mantidos para permitir
repetir os ensaios. A documentação académica do curso é mantida fora deste repositório.
